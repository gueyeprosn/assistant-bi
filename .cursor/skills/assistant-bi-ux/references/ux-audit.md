# Assistant Bi — UX Audit

Utiliser cet audit avant et après toute modification importante de l'interface.

## 1. First impression

En moins de 5 secondes :

- Est-ce que je comprends où je suis ?
- Est-ce que je comprends ce que je peux faire ?
- Est-ce que je vois l'action principale ?

## 2. User flow

Vérifier :

- nombre de clics
- étapes inutiles
- informations demandées
- friction
- erreurs potentielles

Chercher systématiquement à réduire la complexité.

## 3. Visual hierarchy

Vérifier :

- H1
- titres
- CTA
- informations importantes
- informations secondaires

La page doit être scannable.

## 4. Mobile

Tester mentalement : 375px, 390px, 430px.

Vérifier :

- débordements
- boutons
- navigation
- formulaires
- tableaux
- modales
- clavier mobile

## 5. States

Chaque fonctionnalité importante doit avoir :

`DEFAULT` · `LOADING` · `EMPTY` · `ERROR` · `SUCCESS` · `DISABLED`

## 6. Accessibility

Vérifier :

- contraste
- focus
- labels
- clavier
- touch target
- texte alternatif

## 7. Consistency

Comparer avec :

- boutons existants
- cartes existantes
- spacing
- couleurs
- typographie
- radius
- navigation

Si le nouveau composant ne ressemble pas au reste du produit, le corriger.

## 8. Copy

Chaque texte doit être :

- court
- compréhensible
- humain
- orienté action

## 9. AI UX

Pour toute fonctionnalité IA :

- l'utilisateur sait-il que l'IA travaille ?
- sait-il ce que l'IA fait ?
- sait-il quand il peut reprendre la main ?
- peut-il corriger une erreur ?
- comprend-il la provenance des informations ?

## 10. Final score

Donner un score :

- UX : /10
- UI : /10
- Mobile : /10
- Accessibility : /10
- Consistency : /10
- AI UX : /10

Puis identifier les **3 améliorations prioritaires**.

Ne pas proposer 20 améliorations secondaires lorsque 3 problèmes principaux existent.
